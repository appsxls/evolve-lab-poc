# Agent instructions — managed application

This is a simple task manager using plain JavaScript, CSS, and HTML. Preserve the ability to add, complete, and delete tasks. HTTP CRUD is implemented outside this repository at `/api/tasks`; do not assume you can modify the backend. Avoid external dependencies.

After modifying files, run `node --check app.js` and `python3 test_app.py`. Update tests for new frontend behavior when feasible. Never inspect secrets or modify files outside this repository. This project is a local development proof of concept.
