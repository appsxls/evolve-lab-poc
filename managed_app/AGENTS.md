# Agent instructions — managed application

This is a simple task manager using plain JavaScript, CSS, and HTML. Preserve the ability to add, complete, and delete tasks. HTTP CRUD is implemented in `server.py` in the main repository at `/api/tasks`. Application source is tracked by that same repository. Avoid external dependencies.

After modifying files, run `node --check app.js` and `python3 test_app.py`. Update tests for new frontend behavior when feasible. Never inspect secrets or modify files outside the assigned project. This project is a local development proof of concept.
